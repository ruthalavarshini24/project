E-Commerce Customer Churn Early Warning System
ChurnGuard AI
A Machine Learning-based web application that predicts the probability of customer churn in e-commerce and identifies customers who may be at risk of leaving.
 Objectives
•	Predict customer churn using Machine Learning.
•	Analyze customer behavior and purchasing patterns.
•	Classify customers into different risk levels.
•	Identify important churn factors.
•	Provide suitable customer-retention actions.
•	Display results through an interactive dashboard.
Technologies Used
•	Python
•	Scikit-learn
•	XGBoost
•	Pandas
•	HTML5
•	CSS3
•	JavaScript
•	Chart.js
 Machine Learning Models
•	Logistic Regression
•	Decision Tree
•	Random Forest
•	XGBoost
 Features
•	Churn prediction
•	Risk-level classification
•	Customer analytics dashboard
•	Explainable AI insights
•	Customer search and filtering
•	CSV report export
•	Responsive Flipkart-inspired UI
The prototype is implemented as a frontend application using HTML5, CSS3, and JavaScript, with Chart.js for analytics visualizations.
How to Run
1.	Download or clone the repository.
2.	Open the project folder.
3.	Open index.html in a web browser.
Or use VS Code + Live Server.
